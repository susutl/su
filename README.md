# 中药查询系统

一个本地运行的中药辅助工具：把药方文字粘贴进去，自动识别其中每一味药材，并对照《中药学》教材词典给出功效等条目；还能勾选药味、挑选功效短句，一键组写"方解"文字。

纯本地运行，不联网、不上传任何数据。

---

## 一、两种打开方式

### 方式 1：双击 exe（推荐，无需安装任何东西）
直接双击 `中药查询系统.exe` 即可使用。
- 适用系统：Windows 10 / 11（64 位）
- 不需要安装 Python，430 味药材词典已内置在 exe 中
- 首次启动大约有 2~3 秒解压过程，属正常现象

### 方式 2：源码运行（需要 Python 环境）
```bash
pip install PyQt6
python main.py
```
文件结构：

| 文件 | 作用 |
|---|---|
| `main.py` | 图形界面主程序（入口） |
| `herb_matcher.py` | 识别引擎（纯标准库，无第三方依赖） |
| `data/herbs_full.json` | 药材功效词典（430 味） |

> 注意：`data` 文件夹必须和 `main.py` 放在同一目录，程序按自身位置相对查找词典。

## 二、核心功能

### 1. 粘贴药方，自动识别
把处方文字粘贴到左侧输入框（停止输入 0.5 秒自动识别，或按 `Ctrl+Enter` 立即识别）。

**药方格式完全不限**，以下写法都能识别：
- 表格式：`桑叶 10g    紫苏叶 10g    醋五味子 10g`
- 顿号式：`麻黄、桂枝、杏仁、甘草各 10g`
- 病历正文混排：`……治以宣肺平喘，方中麻黄、桑白皮为君……` 后接处方明细

识别结果分两类显示：
- **处方药味**（深色）：带剂味的正式处方用药
- **正文提及**（灰色）：只出现在叙述文字里的药名，供参考

同时能正确处理这些"难缠"情况：
- 炮制品前缀：`蜜麻黄`、`麸炒枳实`、`醋五味子`、`蜜炙款冬花` → 归到正名并保留原写法
- 煎法脚注：`砂仁 10g(后下)` → 剂量与脚注一并提取
- 常用别名：`苏叶→紫苏叶`、`云苓→茯苓`、`杏仁→苦杏仁` 等
- 繁简/异体字与全角数字自动归一

### 2. 对照词典看详情
识别结果区每味药一行，显示**药名、剂量、功效**。
- 文字可以像网页一样**任意拖选复制**（选单个药名、半句功效、跨多行都行），`Ctrl+C` 即可
- 右上角「复制全部结果」一键复制整份对照表
- 点每行末尾的 **[详情]**，下方展开该药的完整条目：类别、药性、功效、主治应用、用法用量、使用注意、出处、别名（点详情不会丢失上方列表）

### 3. 生成方解
点工具栏「**生成方解**」：
1. 弹窗中每味药一个复选框（处方药味默认勾选，正文提及默认不勾）
2. 每味药的下拉框自动把它词典功效**拆成候选短句**（如桑叶 → 疏散风热 / 清肺润燥 / 平抑肝阳 / 清肝明目），选一句；也可选"✎ 手动输入"自己写
3. 下方**实时生成**方解文字，格式：

   > 方中桑叶疏散风热，紫苏叶解表散寒，五味子收敛固涩

4. **相同功效自动合并**：半夏、陈皮都选"燥湿化痰"时，写成

   > 方中半夏、陈皮燥湿化痰，……

   改回不同功效则自动拆开
5. 点「复制方解」进剪贴板，或直接在预览区拖选复制

### 4. 词典热加载（换新词典不用重打包）
点工具栏「**加载药材JSON…**」选择任意 JSON 文件，词典立即替换，识别与方解全部使用新数据。

## 三、词典 JSON 格式

推荐格式（`data/herbs_full.json` 即此结构）：

```json
{
  "桑叶": {
    "category": "解表药",
    "efficacy": "疏散风热，清肺润燥，平抑肝阳，清肝明目。",
    "nature": "苦、甘，寒。归肺、肝经。",
    "indications": "1.风热感冒……",
    "usage": "煎服，5～10g。",
    "caution": "……",
    "origin": "神农本草经",
    "pinyin": ["sangye"],
    "aliases": ["冬桑叶", "霜桑叶", "经霜桑叶"]
  }
}
```

也兼容两种简化结构：
```json
[{ "药名": "桑叶", "功效": "疏散风热，清肺润燥……" }]
{ "桑叶": "疏散风热，清肺润燥，平抑肝阳，清肝明目。" }
```

**给药材加别名的技巧**：识别后若状态栏提示"带剂量但未匹配：某某"，说明词典缺这个写法，在对应药材的 `aliases` 里补一项即可，**不需要改任何代码**。

## 四、性能说明

400 味级别词典采用 Aho-Corasick 多模式自动机 + "药名+剂量"锚定 + 编辑距离容错三级匹配：

- 建词典索引：约 10 ms（430 味）
- 识别一张常规处方：2~10 ms
- 3.6 万字符整页病历：约 70 ms

识别耗时只和**文字长度**有关，与词典里药材数量基本无关——词典扩到几千味依然流畅。

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 双击 exe 没反应 / 提示找不到文件 | 确认是完整 exe（约 36 MB）；从网盘/聊天工具接收时可能被截断，重新传输 |
| 打开后"输入药材识别不了" | 若用的是源码版：检查 `data/herbs_full.json` 是否与 main.py 同级、是否已装 Python+PyQt6；建议直接发 exe 版 |
| 杀毒软件报警/拦截 | PyInstaller 单文件程序常见误报，加入白名单即可（本程序纯本地运行，无网络行为） |
| 首次启动慢 2~3 秒 | 单文件 exe 自我解压，正常；之后启动即开 |
| 图标没变 | 桌面按 F5 刷新，或给文件重命名一次再改回 |
| 某味药识别不出来 | 多为写法不在词典：点[详情]确认，然后把该写法加进 JSON 的 `aliases`，用「加载药材JSON…」重载 |
